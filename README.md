# Gopo App - Duotempus

App web de gestión para empresa de arquitectura y construcción chilena.

## Stack Tecnológico

- **Frontend:** Vite + React + TypeScript + Tailwind CSS v4
- **Backend:** Supabase (PostgreSQL)
- **Librerías:** React Router, TanStack React Query, React Hook Form, Zod, Lucide React, Recharts

## Instalación

```bash
npm install
npm run dev
```

La app estará disponible en `http://localhost:5173`
